# 一期开发路线

## 里程碑 0：工程基线（已完成）

- [x] Spring Boot + Vue 工程骨架
- [x] 前后端合包为一个 JAR
- [x] 管理端核心页面设计
- [x] Flyway 基础表和演示数据
- [x] 读取型管理 API
- [x] 架构、开发、设计和协作文档

## 里程碑 1：接口配置闭环

- [ ] 系统档案 CRUD
- [x] 接口定义 CRUD、发布和停用
- [ ] 接口配置校验与版本号
- [ ] 管理用户登录和基础角色
- [ ] AppKey、Secret 和接口授权

验收标准：管理员能配置一个 WMS → SAP HTTP 接口，并给指定调用方授权。

## 里程碑 2：HTTP 转发运行时

- [x] 动态路由匹配
- [x] Header、Query、Body 透明转发
- [x] 目标 URL 协议、结构约束和禁用重定向
- [x] 连接超时、读取超时和最大报文限制
- [x] Trace ID、脱敏请求响应摘要和异常日志
- [x] 在线接口测试
- [ ] 生产环境目标主机/网段白名单

验收标准：外部系统调用平台地址，平台稳定转发到现有 SAP HTTP 接口并返回原业务响应。

## 里程碑 3：多数据源 SQL API

- [x] 数据源 AES-GCM 加密存储和动态只读连接池
- [x] MySQL、SQL Server、PostgreSQL 驱动适配
- [ ] SAP HANA 驱动适配
- [x] 只读 SQL 校验和命名参数
- [x] 最大行数、执行超时和日志脱敏
- [x] SQL API 发布、测试和调用日志

验收标准：管理员配置一条带参数的只读查询，调用方只提交业务参数即可获取受限结果。

## 里程碑 4：试运行

- [ ] 对接 WMS、SAP 首批真实接口
- [ ] 日志查询、错误分类和导出
- [ ] 配置备份和恢复方案
- [ ] 部署、回滚、监控和运维手册
- [ ] 压力测试与安全检查

一期不在上述范围内加入复杂编排、MQ、定时同步、重试补偿和 Spring Cloud 拆分。
